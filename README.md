# 🧸 PY32F002Aマイコン搭載 「森の動物たち」電子オルゴールプロジェクト (PUYA_orgel_NATURE)

安価でコストパフォーマンスに優れたPUYA製マイコン「PY32F002A」を使用した、おもちゃ修理・換装用の電子オルゴールプロジェクトです。
ウグイスの鳴き声（ホーホケキョ）の実装を原点とし、開発者へのリスペクトを込めて公開されています。

---

## 🛠 プロジェクトの概要と特徴
市販モジュール（YUSIJIE-H1）では対応できなかった「ホーホケキョ」という鳴き声の実現を目指し、マイコン換装による実装を行いました。
- **orgel_SW_F002A_16_NATURE** : 16ピンPY32F002Aを採用、「ホーホケキョ」の鳴き声は SPIフラッシュに収録。
- **特上レベルの音質**：SYSCLK 48MHz、PWM周期は 21μs、PWMステップ数 999 などの優れた設計。
- **楽しく遊べる設計**：タクトSW、CVDタッチセンス、LED点滅をサポート。
- **省エネ・省コスト**：電力消費効率に優れた BTL=3 出力で、100均のおにぎり容器に収まる省スペース設計。
