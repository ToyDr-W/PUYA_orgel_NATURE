# 🧸 PY32F002Aマイコン搭載 「森の動物たち」電子オルゴールプロジェクト (PUYA_orgel_NATURE)

安価なPUYA製マイコン「PY32F002A」を使用したおもちゃ向け電子オルゴールプロジェクトです。「ホーホケキョ」の鳴き声やCVDタッチセンスを実装しています。詳細は[参照ブログ](https://blog.canpan.info/charts/archive/497) および [GitHubリポジトリ](https://github.com/ToyDr-W/PUYA_orgel_SW_BTL) をご覧ください。

---

## 🛠 対象プロジェクト
- **orgel_SW_F002A_16_NATURE** : 16ピンPY32F002Aを使用し、タクトSW、CVDタッチセンス、LED点滅、「ホーホケキョ」の鳴き声を実装したモデルです。
